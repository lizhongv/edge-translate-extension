欢迎使用划词译问 👋

选中网页文字即可翻译、提问、收藏。开始前只需三步完成模型配置：

  1. 选择服务商下方选一个，自动填好接口地址和模型
  2. 填写 API Key点「获取 API Key」到服务商官网申请
  3. 测试连接并保存显示「连接正常」后点击保存

模型服务

支持任意 OpenAI 兼容接口。API Key 仅保存在本机，不会同步或上传。

翻译

问答

选中文字后点「问」，就选中内容与 AI 多轮对话，会话保存在侧边栏。

工具栏与快捷键

选中文字后在选区旁浮出工具栏：翻 · 问 · 存 · 设。

快捷键 翻译 Alt+T；问答可自行绑定

高级

关于

划词译问是开源、免费的划词翻译与问答工具。所有请求由你的浏览器直接发往你配置的模型服务， 不经过任何第三方服务器；设置、历史与备忘录只保存在本机。
